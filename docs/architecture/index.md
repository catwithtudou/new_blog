# Architecture Design

## 软件设计与工程管理

- [《重构：改善既有代码的设计》](books/2403《重构：改善既有代码的设计》/01refactor.md)：从示例、原则与代码坏味道开始。
- [《代码整洁之道》](books/2406《代码整洁之道》/01init.md)：命名、函数、注释与代码组织。
- [《软件设计的哲学》](books/2502《软件设计的哲学》/01init.md)：理解复杂性与模块设计。
- [《人月神话》](books/2411《人月神话》/01init.md)：软件项目中的协作与管理问题。

每本书的后续章节可以通过左侧目录继续阅读。
